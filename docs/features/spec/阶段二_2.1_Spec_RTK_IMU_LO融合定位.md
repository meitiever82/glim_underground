# 阶段二 2.1 子spec：RTK-IMU-LO 融合定位

> 上级：[阶段二总纲](阶段二_Spec_RTK_IMU_LO融合定位_语义VoxelMap.md)
> 定位升级路线：[GNSS 原始观测紧耦合总方案](../../gnss/specs/2026-10-31-gnss-tight-coupling-master-plan.md)
> 下游：[2.2 语义地图子spec](阶段二_2.2_Spec_语义VoxelMap_100mSubmap.md)、[阶段三 Spec](阶段三_Spec_视觉激光跨模态融合_动态感知_在线自标定.md)

## 1. 范围

负责实时 6DoF 位姿估计与状态输出：

- RTK / IMU / 激光里程计融合；
- RTK 质量门控；
- 退化检测与降级；
- 向 2.2 与阶段三输出 `FusionResult`。

不包含：语义地图、地面分割、Submap（2.2）；视觉、检测跟踪、在线标定（阶段三）。

## 2. 两种工作模式

阶段二按 **M-A 位置级** 交付验收；**M-B 原始观测级** 是 master plan 的升级路径，不构成阶段二硬门槛。两模式共用同一套外部接口与状态变量，M-B 只替换/新增 GNSS 观测因子。

| 模式 | RTK 输入 | 验收口径 | 状态 |
|---|---|---|---|
| M-A 位置级 | 北云/610 解算后的位置 + 航向 | RTK 固定解时水平 cm 级 | **阶段二交付基线（按此验收）** |
| M-B 原始观测级 | 逐星伪距/多普勒（+可选载波）双差 | ATE ≤ 1m；剔除 50% 历元、基站断链 30s 不跳变 | master plan P1–P3，阶段二后继续推进 |

精度口径必须分开：M-B 明确接受全局精度从 0.1m 退到亚米级（见 master plan §6 风险登记），**不要把 M-A 的 cm 级指标套到 M-B**。两者共用接口，切换只通过配置选择因子集合。

## 3. 输入

| 输入 | 频率 | 用途 |
|---|---|---|
| IMU（原始角速度/加速度） | ≥100Hz | 预积分、位姿传播、RTK 质量校验 |
| RTK（位置/航向/质量字） | 1–20Hz | 全局绝对约束 |
| 激光里程计位姿（GLIM LO） | 10–20Hz | 局部相对约束 |
| 车辆时间同步 | — | 统一时间基准 |

M-B 额外输入：逐星伪距/多普勒（+载波）、基站差分、星历与基站坐标，由 GNSS 数据链路提供（见 master plan S0/S1），不改变本节其余输入。

## 4. 状态变量

```
pose_k
velocity_k
imu_bias_acc
```

M-B 追加：`T_EW`（ECEF→world 共享变量），与 master plan 的单一 gauge 设计一致。

## 5. 因子

M-A：

```
IMU 预积分因子
RTK 位置因子
RTK 航向因子
激光里程计因子
地面平面约束因子
外参微调因子（阶段三前保持离线固定）
```

M-B 将 `RTK 位置因子` 替换为：

```
基站双差伪距因子
多普勒因子
（可选）跨时间载波双差因子
```

RTK 因子必须带自适应权重，不能固定信任；M-B 用 Huber 核 + DD 共模相消抑制多径/星历误差。

## 6. RTK 质量门控

质量评估至少包含：

- 解算状态：固定解 / 浮点解 / 单点解；
- DOP 值；
- 载噪比；
- 与 IMU 预测位置残差；
- 与 LO 位姿残差；
- 连续跳点检测。

| RTK 状态 | 处理方式 |
|---|---|
| 固定解 + 残差正常 | 正常参与融合 |
| 浮点解 | 降权使用 |
| 单点解 / DOP 过大 | 仅作为弱约束 |
| 与 IMU/LO 残差异常 | 暂时剔除 |
| 连续跳点 | 进入退化模式 |

## 7. 退化检测与降级

监测三类退化：

1. **RTK 退化**：解算状态差、残差大、跳点；
2. **激光退化**：长走廊、空旷矿区、地面结构单一；
3. **IMU 退化**：长时间低激励导致 bias 不可观。

| 退化类型 | 策略 |
|---|---|
| RTK 退化 | 降低 RTK 权重，依赖 LO + IMU + 地面约束 |
| LO 退化 | 提高 RTK/IMU 权重，限制位姿更新幅度 |
| 两者同时退化 | 进入保守模式，只输出 IMU 传播位姿并告警 |

## 8. 接口

```cpp
class FusionEstimator {
public:
    void insert_imu(double stamp,
                    const Eigen::Vector3d& acc,
                    const Eigen::Vector3d& gyro);

    void insert_rtk(double stamp,
                    const Eigen::Vector3d& position,
                    const Eigen::Quaterniond& orientation,
                    const RtkQuality& quality);

    void insert_lidar_odometry(double stamp,
                               const Eigen::Isometry3d& pose,
                               const Eigen::MatrixXd& covariance);

    // 阶段三软约束槽位：阶段二接收地面平面约束，视觉概率由阶段三填 confidence
    void insert_ground_plane(double stamp,
                             const Eigen::Vector4d& plane,
                             double confidence);

    FusionResult get_pose();
    FusionStatus get_status();
};
```

`get_pose()` 直接返回总纲 §5.1 定义的 `FusionResult`，2.2/阶段三只依赖这一种结果类型。

```cpp
struct FusionStatus {
    RtkQuality rtk;          // 状态字 + DOP + 卫星数
    float lo_confidence;     // 0~1
    float imu_confidence;    // 0~1
    bool degraded_rtk;
    bool degraded_lo;
    bool degraded_imu;
};
```

## 9. 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| rtk_max_dop | 2.0 | RTK 质量门控阈值 |
| rtk_residual_sigma | 3.0 | RTK/IMU 残差门控 |
| ground_plane_weight | 0.5–2.0 | 地面约束权重，可自适应 |
| lo_covariance_scale | 1.0 | LO 置信度缩放 |

M-B 追加参数在 master plan 的 v3 设计中给出，不在本表重复。

## 10. 验收

| 指标 | 目标 |
|---|---|
| 轨迹输出频率 | ≥10Hz |
| 轨迹延迟 | <100ms |
| RTK 固定解可用时水平误差（M-A） | 厘米级 |
| 原始观测模式全局误差（M-B，后续推进） | ATE ≤ 1m |
| RTK 退化 5–10s 内 | 轨迹不跳变 |
| 退化切换 | 无位姿跳变，有状态告警 |

## 11. 对外交接

- **→ 2.2**：`FusionResult`（位姿 + 协方差 + 速度 + 状态），≥10Hz；退化时状态位置位，2.2 据此降低更新权重。
- **→ 阶段三**：`T_world_base` + covariance + `FusionStatus`，供 BEV 投影与感知增强定位。
- **← 阶段三**：通过 `insert_ground_plane` 接收视觉地面/静态软约束（槽位已存在，阶段二不实现视觉侧）。
- **→ 诊断/日志**：RTK 状态、LO/IMU 置信度、退化标志，≥5Hz。
