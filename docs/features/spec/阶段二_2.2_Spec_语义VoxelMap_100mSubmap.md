# 阶段二 2.2 子spec：语义 VoxelMap + 100m Submap

> 上级：[阶段二总纲](阶段二_Spec_RTK_IMU_LO融合定位_语义VoxelMap.md)
> 上游：[2.1 定位子spec](阶段二_2.1_Spec_RTK_IMU_LO融合定位.md)
> 下游：[阶段三 Spec](阶段三_Spec_视觉激光跨模态融合_动态感知_在线自标定.md)

## 1. 范围

负责地图侧能力：

- 地面分割（几何方法）；
- 带语义标签的 VoxelMap；
- 以车体为中心的 100m Submap 管理；
- 动态物体掩码回写槽位。

不包含：位姿估计（2.1）；视觉 BEV、3D 检测跟踪、在线标定（阶段三）。

## 2. 输入

| 输入 | 来源 | 用途 |
|---|---|---|
| `PreprocessedFrame`（合并后点云 + 时间戳） | 预处理层 | 体素写入、地面分割 |
| `FusionResult`（位姿 + 时间 + 状态） | 2.1 | 点云配准到 world |
| 地面分割结果 | 本模块 | 写入 GROUND / NON_GROUND |
| 动态掩码（阶段三） | 阶段三 | 从静态地图中剔除/标记 DYNAMIC |

## 3. 地面分割

阶段二先用几何方法，不上深度模型。两套备选：

| 方案 | 优势 | 适用性 |
|---|---|---|
| LineFit | 非平面适应强、CPU 实时、内存小 | 坡道、矿场地面 |
| GenericGrid | 基于高度图/坡度图，SemanticKITTI 地面 IoU 94.78% | 高密度点云、复杂地形 |

矿场地面起伏较大，优先 **LineFit**；坡道/坑洼分割不稳定时切换 GenericGrid 或 Patchwork++。

输出：

```
ground_points
non_ground_points
ground_plane_params
segmentation_confidence
```

`ground_plane_params` 同时供 2.1 的 `insert_ground_plane` 使用。

## 4. 语义 VoxelMap

在 GLIM 现有 Point Cloud Submap 基础上扩展体素结构：

```cpp
struct SemanticVoxel {
    float occupancy_prob;
    uint8_t semantic_label;   // 见下方枚举
    Eigen::Vector3f plane_normal;
    float plane_d;
    uint32_t update_count;
    double last_update_time;
    float height_mean;
    float height_var;
    // 阶段三追加（不改变上述基础字段布局）
    // float dynamic_prob;
    // uint32_t associated_track_id;
    // float visual_semantic_confidence;
    // 阶段四预留
    // float reflectance_mean;
    // float traversability;
};
```

标签枚举从阶段二起就按阶段三的多类别设计，避免阶段三重写地图结构：

```
UNKNOWN
GROUND
NON_GROUND_STATIC
VEHICLE
PEDESTRIAN
VEGETATION
ORE_PILE
DYNAMIC_UNKNOWN
```

更新规则：

- 地面点写入 `GROUND`；
- 非地面静态点写入 `NON_GROUND_STATIC`；
- 检测/跟踪确认的高变化区域标记 `DYNAMIC_UNKNOWN` 或对应类别（阶段三）；
- 每个体素维护更新时间戳，用于老化；
- 地面体素额外维护平面参数，用于位姿优化；
- 动态掩码命中的体素不参与静态地图更新。

## 5. 100m Submap 管理

以车体当前位置为中心维护局部地图：

- 子地图尺寸：100m × 100m，或半径 50m；
- 近场体素分辨率：0.1–0.2m；
- 远场体素分辨率：0.3–0.5m；
- 超出范围的体素降级存档；
- 动态物体掩码不参与静态地图更新；
- 子地图切换时做权重衰减，避免边界跳变。

## 6. 接口

### 6.1 语义地图

```cpp
class SemanticVoxelMap {
public:
    void update(const PreprocessedFrame& frame,
                const Eigen::Isometry3d& pose,
                const GroundSegmentationResult& seg);

    SemanticVoxel::Ptr query(const Eigen::Vector3d& point) const;

    std::vector<SemanticVoxel> get_submap(
        const Eigen::Vector3d& center, double radius) const;

    // 阶段三动态掩码回写（按跟踪目标）
    void remove_dynamic_objects(
        const std::vector<ObjectTrack>& tracks);

    // 阶段三动态掩码回写（按体素掩码，后续扩展）
    void apply_dynamic_mask(const DynamicMask& mask);
};
```

### 6.2 Submap 管理器

```cpp
class SubmapManager {
public:
    void set_center(const Eigen::Vector3d& center);

    void add_voxels(const std::vector<SemanticVoxel>& voxels);

    void prune(double keep_radius);

    SemanticVoxelMap::Ptr get_active_submap() const;
};
```

### 6.3 与阶段三共享的类型

`ObjectTrack` / `DynamicMask` 由阶段三产生，阶段二只声明并消费，不实现跟踪与检测。最小契约：

```cpp
struct ObjectTrack {
    int id;
    double stamp;
    Eigen::Isometry3d pose;      // world
    Eigen::Vector3f size;
    uint8_t semantic_label;      // 复用上方枚举
    float confidence;
    Eigen::Vector3f velocity;
};

struct DynamicMask {
    double stamp;
    // 体素级或点级动态标记，由阶段三定义实现
};
```

阶段三的检测/跟踪输出必须能无损映射到本结构：`bbox` → `pose + size`，`class` → `semantic_label`，`id/velocity/confidence` 直接对应。映射不成立的字段，在阶段三 §5.2 调整输出，而不是改这里的基础字段。

## 7. 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| submap_radius | 50.0m | 100m 直径子地图 |
| near_resolution | 0.15m | 近场体素分辨率 |
| far_resolution | 0.4m | 远场体素分辨率 |
| voxel_update_min_interval | 0.1s | 体素更新最小间隔 |

## 8. 验收

| 指标 | 目标 |
|---|---|
| VoxelMap 更新频率 | ≥10Hz |
| 地面分割实时性 | 单帧 <20ms |
| 地面分割稳定性 | 坡道/坑洼无明显翻转 |
| Submap 显存占用 | Orin 上稳定，不持续增长 |
| Submap 切换连续性 | 无边界跳变 |
| 标签一致性 | GROUND/NON_GROUND_STATIC 不频繁抖动 |

## 9. 与阶段三的交接

| 阶段三环节 | 阶段二提供 |
|---|---|
| BEV 投影到激光坐标系（§4.2） | 2.1 的 `T_world_base`；2.2 的 `get_submap(center, radius)` |
| 跨模态语义对齐（§4.2） | 每个体素的 `semantic_label` + 位置；置信度由阶段三写入 `visual_semantic_confidence` |
| 动态掩码生成/回写（§4.3） | `remove_dynamic_objects(ObjectTrack)` / 预留 `apply_dynamic_mask(DynamicMask)` |
| 多类别语义（§4.1） | 枚举已含 VEHICLE / PEDESTRIAN / VEGETATION / ORE_PILE / DYNAMIC_UNKNOWN |
| 感知增强定位（§4.5） | 阶段三产出 `static_points = raw_points - dynamic_mask`；体素权重更新槽位已留 |
| 体素结构扩展（§10） | 基础字段稳定，允许追加 `dynamic_prob` / `associated_track_id` / `visual_semantic_confidence` |

约束：2.2 不主动依赖阶段三模块；阶段三未接入时，地图只更新 GROUND / NON_GROUND_STATIC，系统可独立运行。
