# 设计：紧耦合原型验证——T_ins_lidar 外参进图联合估计

- 日期：2026-10-19
- 状态：已执行完毕，结果见 `docs/gnss/field/2026-10-19-tight-coupling-prototype-report.md`
- 结果速览：锁外参紧耦合 ATE=0.100m（最强前端）；外参自由病态（多模态 + 610 杆臂混淆，代数证明），在线标定平移不可行
- 作者：Hermes（boonraygrn 会话）
- 关联：调研报告 `kiss_icp_eval/REPORT_final.md` §2.8（松耦合在线标定已证不可靠）、`2026-10-19-shared-gauge-and-fixed-bootstrap-design.md`（GLIM 侧 gauge 调查）

## 1. 要验证的问题

在 **610 IMU + RTK 位置 + 激光** 的紧耦合框架下，把 `T_ins_lidar`（610 系 → at128 系外参，标称 [1.887, -1.006, -0.652] + 单位旋转）作为图内变量联合估计：

- **Q1（主要）**：外参可估且收敛到跨段一致值吗？
- **Q2**：外参自由后，地图精度（ATE）相比"锁标称值"变好吗？
- **Q3**：姿态激励够吗——可观子空间是几维（预计水平平移+全旋转可观，Lz 边缘）？

**与调研已证伪方案的区别**（为什么不重蹈覆辙）：调研是 KISS 纯 LO + 位置型 RTK 的**松耦合**，姿态来自 LO 会漂，杆臂信号 `ΔR·L` 被淹没；本方案 IMU 预积分提供高频姿态通道，重力锁 roll/pitch，且状态建在 610 系——"IMU 不是雷达自带的"这一 FAST-LIO 卡点在本架构下不存在（外参本来就是显式变量）。

## 2. 数据预分析结论（seg_153000_153351，231s）

| 条件 | 实测 | 判定 |
|---|---|---|
| yaw 激励 | 总转角 1731°，角速度 p95=15.7°/s max=32°/s | 强，水平杆臂可观 ✓ |
| pitch/roll 激励 | pitch 跨度 4.65°（坡道），roll 7.45° | 中等；Lz 信号 ≈ 1.89m×sin(4.65°)≈0.15m，对 RTK 竖直噪声（cm 级）边际可观 |
| 高程 | 跨度 1.62m | 辅助 |
| IMU | `/cgi610/imu` 100Hz，acc_z mean 9.79 ✓，gyr 量级合理 | 健康 ✓ |
| GNSS | `/cgi610/fix` 10Hz 全程 RTK-FIXED | 强绝对约束 ✓ |
| 时间同步 | 两设备 header.stamp 均为接收时标（diff=0.0ms） | 同一时钟域 ✓；设备内部管线延迟差（串口 vs 网口）毫秒级未知，作为风险处理 |
| 双天线航向 | 只存在于 `/cgi610/odom` 的 INS 融合姿态里，无独立原始话题 | v1 不用（避免与 IMU 原始量双重计数）；v2 可作软姿态先验 |

**结论：数据条件够做水平平移 + 旋转的外参估计；Lz 边际可观，设计为"紧先验 + 可估但低信任"。**

## 3. 框架设计

### 3.1 状态

```
每个关键帧 k（10Hz 激光帧驱动）:
  X_k = (T_wb_k, v_k, bg_k, ba_k)     # 610 IMU 系位姿、速度、陀螺/加计零偏
全局共享变量:
  T_ins_lidar = (R_il, t_il)          # 待估外参,标称值作初值
```

### 3.2 因子

| 因子 | 内容 | 权重 |
|---|---|---|
| IMU 预积分 | 相邻关键帧间（GTSAM PreintegratedImuMeasurements，100Hz 原始量） | IMU 噪声按 MEMS 档位， Allan 参数初值后调 |
| GNSS 位置先验 | INSPVA 输出位置 = IMU 参考点（610 内部已做天线杆臂补偿）→ 直接约束 T_wb 平移 | 按 fix 协方差，全程 FIXED → σ≈2-5cm |
| 激光帧间约束 | KISS/GICP 相邻+回环窗口配准得 lidar 系相对位姿 ΔT_ll；经 ExpressionFactor 换算 `ΔT_bb = T_il · ΔT_ll · T_il⁻¹` 约束两关键帧 | 配准协方差（调研的逐帧信息矩阵做法可复用） |
| 外参先验 | 标称值 ± 水平 0.2m / z 0.1m / 旋转 2° | 松先验（可估空间内），防无激励段漂移 |
| 零偏随机游走 | 标准 Brownian | — |

**关键设计点**：激光约束经 `T_ins_lidar` 表达式因子进图（GTSAM ExpressionFactor，自动微分），外参的梯度来自每一个激光约束——这是"雷达观测参与外参估计"的通道，也是和调研松耦合（外参只出现在 RTK 锚点换算里）的本质区别。

### 3.3 求解

沿用调研的 iSAM2 增量模式（`lrtk_odometry_dd.cpp` 已验证在线可行，~1ms/帧量级），批量模式用于对照上界。

## 4. 实现计划

在 `lrtk_odometry_calib.cpp` 骨架上升级（保留其 L 变量/prior 机制与评估脚本），新增 IMU 通道：

1. 数据装载：bag → 关键帧激光 + IMU 序列 + fix 序列（rosbag2_py 或 C++ rosbag2）
2. IMU 预积分模块（GTSAM 原生，610 系）
3. KISS 前端改成输出关键帧间相对约束 + 协方差（调研已有此代码路径）
4. 因子图组装 + ExpressionFactor(T_il)
5. 评估脚本：ATE（对 gt_at128_flu）+ 外参收敛轨迹 + 与调研 calib 版同口径的失败模式对照（初值给真值是否还漂）

工作量预估：~600 行 C++（骨架复用调研），一天内出首个结果。

## 5. 验证方案（通过标准）

| # | 实验 | 通过标准 |
|---|---|---|
| E1 | 锁标称外参跑 seg B | 复现基线 ATE（对照组） |
| E2 | 外参自由 + 松先验 | **ATE ≤ E1**；外参估计值与标称差在物理合理范围（<10cm 水平） |
| E3 | 决定性对照（调研的失败模式）：初值给"真值"（标称），看是否漂走 | 不漂（收敛轨迹稳定在初值 ±5cm）→ 紧耦合确实修复了调研的架构性偏差 |
| E4 | 跨段一致性：seg A 同样跑 | 两段估出的外参差 <5cm → 估计的是真实物理量 |
| E5 | Lz 可观性检查 | 报告 Lz 的后验方差；若不可观（方差不收敛）则 Lz 锁先验，如实记录 |

**判负标准**（诚实条款）：若 E3 仍然漂走，说明激励/数据质量不足以支撑在线标定，结论="该数据上 T_ins_lidar 不可在线估"，回到离线标定路线，同样是有效结论。

## 6. 风险

- **R1 设备管线延迟差**（串口 vs 网口，毫秒级）：10ms@8m/s=8cm 伪外参信号。缓解：v1 先忽略；若 E3 失败且残差呈速度相关模式，v2 加 td 状态或离线运动时标对齐
- **R2 MEMS 零偏量级**：610 是车载 MEMS，零偏不稳会污染 pitch/roll 通道进而污染 Lz。缓解：零偏进状态 + E5 的后验方差检查
- **R3 双重计数**：v1 不用 `/cgi610/odom` 的融合姿态，只用原始 IMU + fix 位置，避免与 INS 内部解重复计数
- **R4 激光约束质量**：seg B 转弯密，KISS 相对约束在急弯段的协方差要如实（复用调研的逐帧信息矩阵），否则外参梯度被坏约束带偏
