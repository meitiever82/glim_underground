## 1. 问题

当前紧耦合原型的 GNSS 锚是 610 的 **INSPVA 融合位置**——过了 610 内部解算，带来两个已实证的结构性问题：

1. **杆臂混淆**：610 按其内部配置的天线杆臂补偿输出位置，其误差与 T_ins_lidar 平移误差在观测方程中精确同构（报告 §4 代数证明）——在线外参标定因此不可行。
2. **信息损失**：只有解算后的位置（10Hz、FIX/FLOAT 粗粒度标志），没有逐星观测。少于 4 星时 610 不解算，信息全丢；多径/NLOS 只能在事后从残差里猜。

接收机有**原始观测流**（rangecmpb：伪距+载波相位+多普勒，逐星逐历元），测试车上 oemraw→ros_stream_adapter→rtkrcv 链路已跑通。把位置因子换成原始观测因子是文献验证过的成熟升级路径（Beuchert ICRA 2023：无基站 1-2m 全局 + 载波双差局部 <10cm；GVINS/GLIO 同族）。

**目标**：参照 Beuchert 设计，把现有 tck 图的 INSPVA 位置因子升级为 **伪距因子（星间单差）+ 跨时间载波双差因子**，T_EW（局部系↔全局系变换）进图在线估计，彻底消除 610 混淆，并获得 GNSS 断续的隐式鲁棒性。

**非目标**：不做接收机跟踪环路级深耦合（硬件封闭，文献也表明激光帮不上环路层）；不做在线外参标定（已证伪，见前置报告，Rotation Only）；不替代 GLIM 前端（原型继续独立演进，验证后再谈嫁接）。

## 1.5 三条技术路线对比（三篇精读，2026-10-28）

**共同骨架**（三家独立一致，本设计继承）：原始观测进图（不用接收机位置解）；局部系↔ECEF 变换（T_EW）在线估计；IMU 预积分做高频骨架；激光相对因子 + GNSS 原始观测分层融合（拒绝 LIO-SAM 式"RTK 解 vs 激光解双绝对约束比权重"）。

| 维度 | **GAINS**（黄国权组, ICRA'22） | **Beuchert**（Oxford, ICRA'23） | **GLIO2**（2026） |
|---|---|---|---|
| 局部传感器 | 视觉（MSCKF-VIO） | 激光 ICP（可选） | 激光 S2MS-VGICP（GPU 并行） |
| **大气误差处理** | 时序差分（同星跨历元） | 伪距建模大气 + 载波星间×时间双差 | **基站双差**（rover−参考站） |
| 载波相位 | 用（差分后） | 用（跨时间双差消模糊度） | 不用（伪距+多普勒足够） |
| 多普勒 | 建模 | 不用 | 建模（全局速度观测） |
| 钟差 | 状态（bias+drift） | 每星座状态 | 双差消掉，无状态 |
| 基站 | 不需要 | 不需要 | 需要（单接收机变体在附录） |
| 在线标定 | IMU-GNSS 时空标定（外参+td） | T_EW | T_EW + 重力方向（2DOF） |
| 估计器 | EKF（MSCKF） | iSAM2 FGO | 滑窗 FGO（GPU） |
| 精度 | 亚米 | 无基站 1-2m（载波局部 <10cm） | urban canyon 0.9-1.3m（最好） |

**选型结论**：有 RTK 基站链路 → 基站双差（GLIO2 路线）为主；时间差分（GAINS/Beuchert）为基站断链备份；载波降级为遮挡场景可选增强。

## 2. 方案

### 2.1 图结构变化（对 tck_calib_v2 的 diff）

| 组件 | 现状（v2） | 升级后（v3） |
|---|---|---|
| 状态 X/V/B | 不变（10Hz 关键帧） | 不变 |
| 共享变量 | T_li（锁死） | T_li（锁死，离线标定值）+ **T_EW（SO(3)×R³，在线估计，松先验）** |
| GNSS 因子 | INSPVA 位置因子（经 T_li） | **删除**。替换为：①伪距星间单差因子（逐历元、每对星一个）②载波跨时间双差因子（2 星 × 2 历元，消模糊度） |
| 激光 between | KISS 相对位姿 + 信息矩阵 | 不变 |
| IMU 预积分 | 经 T_li 双线性 | 不变 |
| 钟差状态 | 无 | 不需要（单差消接收机钟差，双差消卫星钟差+模糊度） |

### 2.2 伪距因子（基站双差 DD 为主，时间差分备份）

> 2026-10-28 修订（三篇精读结论）：原方案的星间单差改为**基站双差**为主——我们有 RTK 差分链路（rtkrcv 基站流已通），基站双差最简单、精度最好（GLIO2 urban canyon 0.9-1.3m 只用伪距+多普勒）、且顺手消掉接收机+卫星钟差（状态里连钟差都不用建）。时间差分（GAINS/Beuchert 路线）留作基站断链时的备份。

每历元：流动站星 m 与基站星 m 的伪距做站间差，再与基准星（连续可见最长）做星间差：

```
r_DD = (‖sⁿ − T_EW·T_ant(p_i)‖ − ‖sᵐ − T_EW·T_ant(p_i)‖) − DD_观测
DD_观测 = (ρ_roverⁿ − ρ_baseⁿ) − (ρ_roverᵐ − ρ_baseᵐ)
```

- 双差消掉：接收机钟差、卫星钟差、硬件延迟、短基线大气延迟——噪声模型只需吸收残余（σ 起步 0.5m，Huber 核抗多径）
- 基站观测流：rtkrcv 差分链路的基准站侧（已部署）；无基站时降级为时间差分（同星跨历元，GAINS §IV）
- 卫星位置/钟差：广播星历（rtkrcv 已能解 rangecmpb 星历；或预载 RINEX nav）
- T_ant(p)：天线相位中心 = 机体系经**已知**天线杆臂（离线标定值，与 T_li 各自独立建模——610 混淆消失的关键）
- 多径防护：Huber 核 + 残差阈值剔除（Beuchert 同款）

### 2.3 载波双差因子（跨时间，消模糊度）——降级为可选

> 2026-10-28 修订：GLIO2 证明有基站时伪距+多普勒即可达 0.9m 级；载波的价值集中在无基站/遮挡场景（Beuchert 的卖点）。优先级降为可选增强，P2 视伪距残差水平决定是否实施。

对连续锁定的星对 (m,n) 在历元 i,j 间构双差（Suzuki time-relative / Beuchert Eq.10）：

```
r_DD = (‖sⱼⁿ−T pⱼ‖−‖sⱼᵐ−T pⱼ‖) − (‖sᵢⁿ−T pᵢ‖−‖sᵢᵐ−T pᵢ‖) − ΔΔφ
```

- 模糊度整数、卫星钟差、大气缓变量全部消掉；载波噪声 mm 级 → σ 起步 0.02m
- 只在**连续锁定**（LLI 无周跳）区间内连因子；周跳断开即换参考段——单阶段隐式处理断续，不需要模式切换
- 这是局部光滑性的主要来源（Beuchert 实验：纯载波双差终点 <10cm）

### 2.4 T_EW 在线估计

- 局部系（激光地图系）↔ ECEF 的变换进图，初值由首段伪距 SPP 粗定（或沿用 ENU 原点附近近似）
- 先验给松（位置 10m、旋转 5°）——它是伪距因子唯一的绝对约束通道，收敛后稳定在 cm~dm 级
- 顺带解决 GLIM 侧双 gauge 矛盾的架构问题（单一 T_EW 共享变量，odom/map 分叉不再存在）

### 2.5 数据来源（关键约束）

**红沙泉 610 数据集没有原始观测，本升级必须换数据**：

- 平台：中煤车（192.168.7.11 + gnss_bringup 已部署，rangecmpb 已验证）
- 需采集：rangecmpb 原始观测 + 星历 + 激光 + **IMU（接收机内部 IMU 原始数据，已确认可获得）**
- 场景：开阔地起步（等效段 A 难度），含转弯激励；后续再采遮挡段验证断续鲁棒性
- 参考真值：rtkrcv RTK FIX 解（差分链路已在车上）作 ATE 参考；地图指标复用 map_quality.py 管线

### 2.6 里程碑与验收

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0 数据 | 华测采集 + rangecmpb 解析器（→ 逐历元伪距/载波/星历 csv）+ 新数据上跑通现有 v2（位置因子用 rtkrcv FIX 输出） | v2 在新数据上 ATE < 0.5m（建立基准） |
| P1 伪距 | **基站双差**伪距因子替换位置因子，T_EW 进图 | 收敛；ATE ≤ 1m（GLIO2 有基站伪距路线 0.9m 级，伪距噪声地板不再适用） |
| P2 载波（可选，降级） | 加入跨时间双差因子（基站断链/遮挡场景才必需） | 局部光滑性指标显著优于 P1；基站断链 30s 内轨迹无跳变 |
| P3 鲁棒性 | 人为剔除部分历元/星（模拟遮挡） | 剔除 50% 历元下轨迹无跳变；对比 v2 位置因子版在同等剔除下失效 |

每阶段沿用原型工作流：C++ 单文件演进（tck_calib_v3.cpp）+ 批量 LM 先验证收敛、iSAM2 后验证在线。

## 3. 风险与开放问题

1. **伪距噪声地板**：无差分链路时伪距定位 1-2m 级——我们的全局精度反而可能从 0.1m 退到亚米级？**不会**：载波双差提供 mm 级相对约束，全局由 RTK 差分链路的基准站观测兜底（rangecmpb 的基站侧也可进图做单差——视 P1 结果决定是否加基站伪距差分因子，那是经典 RTK 图内实现）。
2. **星历质量**：广播星历轨道误差 ~1m，全进伪距残差——Huber 核 + SD 部分相消；P1 验收会暴露。
3. **工作量集中点**：rangecmpb 二进制解析（RTKLIB 有现成解码，可抽出来用）+ 因子 Jacobian（伪距对位置是解析式，比现在的数值微分还简单）。

## 3.5 新增：外参在线估计可重新评估（旋转+td，平移仍排除）

GAINS 在线估计 IMU-GNSS 时空标定（外参+时间偏移）且 work——与我们"外参在线已证伪"的结论**不矛盾**：我们证伪的是 INSPVA 位置因子形态下 T_ins_lidar **平移**（610 杆臂混淆，§3.5 前报告 §4），而**旋转**在原型 E2 中已有初步收敛证据（只是批量多初值下不够扎实）。走原始观测路线后混淆消失，**旋转 + 时间偏移 td 的在线估计**可以重新立项评估（P3 之后）；平移维持离线标定不动。

## 3.6 远期扩展：车车动基线协同（固定基站不动）

固定基准站的站星双差不变（绝对锚），**再叠加车车原始观测双差作为附加约束**：

- 因子形式 `DD(车A, 车B, 星m, 星n)` 与基站双差因子并存，两车状态同图联合估计
- 收益：某车遮挡/RTK 掉链时借邻车观测链维持相对约束；车车相对位置 cm 级（矿区多车防撞/编队的免费约束）
- 新增工程项仅两条：车车原始观测通信链路、两机历元对齐（对齐到同一 GPS 历元，钟差由双差消）
- 线索：华测双天线定向本身就是动基线 RTK（主辅天线互为基准），固件链路层已通，车车版只是跨设备扩展
- 时机：P3 之后另立项目评估，不在本设计范围

## 4. Out of Scope

- 跟踪环路级深耦合（深耦合定义见调研记录，硬件不可达）
- PPP（无基站精密单点）——Beuchert 无基站路线的完整版，作为远期选项
- 在线外参/杆臂估计——**分量处理**：平移在 INSPVA 形态下已证伪（610 混淆），不做；旋转有初步证据可行但不扎实，连同时空标定（外参旋转+时间偏移 td）在原始观测路线下 P3 后重新评估（见 §3.5）。本设计内外参维持离线标定
- GLIM 集成（原型验证通过后再评估）
