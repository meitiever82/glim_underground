# 设计稿：原始 GNSS 观测紧耦合升级（伪距+载波双差因子进图）

- 日期：2026-10-22
- 状态：**评审稿**
- 前置：
  - 紧耦合原型报告 `docs/gnss/field/2026-10-19-tight-coupling-prototype-report.md`（610 INSPVA 位置因子版，段 A 0.100m / 段 B 0.174m，但外参自由病态、610 杆臂混淆）
  - 参照文献：Beuchert, Camurri, Fallon, *Factor Graph Fusion of Raw GNSS Sensing with IMU and Lidar*, ICRA 2023（arXiv:2209.14649，开源 JonasBchrt/raw-gnss-fusion）

## 1. 问题

当前紧耦合原型的 GNSS 锚是 610 的 **INSPVA 融合位置**——过了 610 内部 INS 黑盒，带来两个已实证的结构性问题：

1. **杆臂混淆**：610 按其内部配置的天线杆臂补偿输出位置，其误差与 T_ins_lidar 平移误差在观测方程中精确同构（报告 §4 代数证明）——在线外参标定因此不可行。
2. **信息损失**：只有解算后的位置（10Hz、FIX/FLOAT 粗粒度标志），没有逐星观测。少于 4 星时 610 不解算，信息全丢；多径/NLOS 只能在事后从残差里猜。

北云接收机有**原始观测流**（rangecmpb：伪距+载波相位+多普勒，逐星逐历元），geacx 车上 oemraw→ros_stream_adapter→rtkrcv 链路已跑通。把位置因子换成原始观测因子是文献验证过的成熟升级路径（Beuchert ICRA 2023：无基站 1-2m 全局 + 载波双差局部 <10cm；GVINS/GLIO 同族）。

**目标**：参照 Beuchert 设计，把现有 tck 图的 INSPVA 位置因子升级为 **伪距因子（星间单差）+ 跨时间载波双差因子**，T_EW（局部系↔全局系变换）进图在线估计，彻底消除 610 混淆，并获得 GNSS 断续的隐式鲁棒性。

**非目标**：不做接收机跟踪环路级深耦合（硬件封闭，文献也表明激光帮不上环路层）；不做在线外参标定（已证伪，见前置报告）；不替代 GLIM 前端（原型继续独立演进，验证后再谈嫁接）。

## 2. 方案

### 2.1 图结构变化（对 tck_calib_v2 的 diff）

| 组件 | 现状（v2） | 升级后（v3） |
|---|---|---|
| 状态 X/V/B | 不变（10Hz 关键帧） | 不变 |
| 共享变量 | T_li（锁死） | T_li（锁死，离线标定值）+ **T_EW（SO(3)×R³，在线估计，松先验）** |
| GNSS 因子 | INSPVA 位置因子（经 T_li） | **删除**。替换为：①伪距星间单差因子（逐历元、每对星一个）②载波跨时间双差因子（2 星 × 2 历元，消模糊度） |
| 激光 between | KISS 相对位姿 + 信息矩阵 | 不变 |
| IMU 预积分 | 经 T_li 双线性 | 不变 |
| 钟差状态 | 无 | 不需要（单差消接收机钟差，双差消卫星钟差+模糊度） |

### 2.2 伪距因子（星间单差 SD）

每历元选**连续可见时间最长的星**为基准星 m，其余每颗 n 构成一个单差因子：

```
r_SD = (‖sⁿ − T_EW·T_ant(p_i)‖ − ‖sᵐ − T_EW·T_ant(p_i)‖) − (ρⁿ − ρᵐ)
```

- 接收机钟差、硬件延迟在星间差中消掉；短基线下电离层/对流层残差 <0.5m，由噪声模型吸收（σ 起步 1m，Huber 核抗多径）
- 卫星位置/钟差：广播星历（rtkrcv 已能解 rangecmpb 星历；或预载 RINEX nav）
- T_ant(p)：天线相位中心 = 机体系经**已知**天线杆臂（离线标定值，与 T_li 各自独立建模——610 混淆消失的关键）
- 多径防护：Huber 核 + 残差阈值剔除（Beuchert 同款）

### 2.3 载波双差因子（跨时间，消模糊度）

对连续锁定的星对 (m,n) 在历元 i,j 间构双差（Suzuki time-relative / Beuchert Eq.10）：

```
r_DD = (‖sⱼⁿ−T pⱼ‖−‖sⱼᵐ−T pⱼ‖) − (‖sᵢⁿ−T pᵢ‖−‖sᵢᵐ−T pᵢ‖) − ΔΔφ
```

- 模糊度整数、卫星钟差、大气缓变量全部消掉；载波噪声 mm 级 → σ 起步 0.02m
- 只在**连续锁定**（LLI 无周跳）区间内连因子；周跳断开即换参考段——单阶段隐式处理断续，不需要模式切换
- 这是局部光滑性的主要来源（Beuchert 实验：纯载波双差终点 <10cm）

### 2.4 T_EW 在线估计

- 局部系（激光地图系）↔ ECEF 的变换进图，初值由首段伪距 SPP 粗定（或沿用 ENU 原点附近近似）
- 先验给松（位置 10m、旋转 5°）——它是伪距因子唯一的绝对约束通道，收敛后稳定在 cm~dm 级
- 顺带解决 GLIM 侧双 gauge 矛盾的架构问题（单一 T_EW 共享变量，odom/map 分叉不再存在）

### 2.5 数据来源（关键约束）

**红沙泉 610 数据集没有原始观测，本升级必须换北云数据**：

- 平台：geacx 车（192.168.7.11，北云 + gnss_bringup 已部署，rangecmpb 已验证）
- 需采集：rangecmpb 原始观测 + 星历 + 激光（AT128?/该车雷达）+ IMU（来源待拍板，见 §5）
- 场景：开阔地起步（等效段 A 难度），含转弯激励；后续再采遮挡段验证断续鲁棒性
- 参考真值：rtkrcv RTK FIX 解（差分链路已在车上）作 ATE 参考；地图指标复用 map_quality.py 管线

### 2.6 里程碑与验收

| 阶段 | 内容 | 验收 |
|---|---|---|
| P0 数据 | 北云采集 + rangecmpb 解析器（→ 逐历元伪距/载波/星历 csv）+ 新数据上跑通现有 v2（位置因子用 rtkrcv FIX 输出） | v2 在新数据上 ATE < 0.5m（建立基准） |
| P1 伪距 | SD 伪距因子替换位置因子，T_EW 进图 | 收敛；ATE 相对 P0 基准不劣化超 2 倍（伪距噪声 m 级，预期 1-3m 属正常——精度靠 P2 补） |
| P2 载波 | 加入跨时间双差因子 | 局部光滑性指标（相邻帧位姿差抖动）显著优于 P1；全局 ATE ≤ 0.5m |
| P3 鲁棒性 | 人为剔除部分历元/星（模拟遮挡） | 剔除 50% 历元下轨迹无跳变；对比 v2 位置因子版在同等剔除下失效 |

每阶段沿用原型工作流：C++ 单文件演进（tck_calib_v3.cpp）+ 批量 LM 先验证收敛、iSAM2 后验证在线。

## 3. 风险与开放问题

1. **伪距噪声地板**：无差分链路时伪距定位 1-2m 级——我们的全局精度反而可能从 0.1m 退到亚米级？**不会**：载波双差提供 mm 级相对约束，全局由 RTK 差分链路的基准站观测兜底（rangecmpb 的基站侧也可进图做单差——视 P1 结果决定是否加基站伪距差分因子，那是经典 RTK 图内实现）。
2. **星历质量**：广播星历轨道误差 ~1m，全进伪距残差——Huber 核 + SD 部分相消；P1 验收会暴露。
3. **工作量集中点**：rangecmpb 二进制解析（RTKLIB 有现成解码，可抽出来用）+ 因子 Jacobian（伪距对位置是解析式，比现在的数值微分还简单）。

## 4. Out of Scope

- 跟踪环路级深耦合（深耦合定义见调研记录，硬件不可达）
- PPP（无基站精密单点）——Beuchert 无基站路线的完整版，作为远期选项
- 在线外参/杆臂估计（已证伪）
- GLIM 集成（原型验证通过后再评估）
